# Vihaan Group — Real Estate Website

A static real estate website for **Vihaan Group**, featuring the **Green Heaven** project (Sector 16, Greater Noida West).

## Pages
- `index.html` — Homepage (hero, stats, featured projects, amenity gallery, testimonials)
- `projects.html` — Filterable project listing
- `project-detail.html` — Dynamic project detail (gallery, amenities, enquiry form)
- `about.html` — About the developer
- `blog.html` — Market insights / blog
- `contact.html` — Contact + enquiry form

## Tech
- Pure HTML / CSS / JavaScript (no framework, no build step)
- Design system: Gold `#D4A52C`, Deep Emerald `#0B3B2E`, White `#FFFFFF`
- `js/data.js` — central content (projects, blogs, testimonials, amenities)
- `js/main.js` — interactivity (nav, counters, sliders, filters, lightbox, forms)

## Run locally
Serve the folder from any static server:
```
npx serve
```
or open `index.html` directly.
